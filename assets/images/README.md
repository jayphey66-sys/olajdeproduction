## Tips for best results:

1. **Keep consistent style** - All photos should have similar color grading and tone
2. **Proper lighting** - Well-lit images look professional
3. **Consistent dimensions** - Don't mix portrait and landscape in same section
4. **Optimize file sizes** - Use TinyPNG.com to compress
   - Target: 50-100KB per image
   - Larger images: 100-150KB max
5. **Web-friendly format** - Use JPG (best for photos) or PNG (for graphics)
6. **Test quality** - View on different screens to ensure clarity

## How to replace images:

1. Take/edit your photos to the recommended sizes
2. Export as JPG with 75-85% quality
3. Name them exactly as listed above
4. Replace the corresponding files in this folder
5. The website will automatically display your images!
